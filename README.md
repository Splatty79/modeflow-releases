# ModeFlow releases

Official APK downloads and update metadata for the private ModeFlow Android app.

## Install or update

Download the newest APK from [Releases](https://github.com/Splatty79/modeflow-releases/releases/latest), open it on the Oppo phone, then approve **Install** or **Update**.

ModeFlow also checks `latest.json` when it opens and displays an **Update** button whenever a newer signed build is available. Android verifies that every update uses the same app package and signing certificate before it can replace the installed app.

This repository contains release files only. ModeFlow source code, signing material, routines and household information are not stored here.
